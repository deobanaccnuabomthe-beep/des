Place delivered assets here, matching the file list in the spec (section 8):

- `base_mesh.glb` — base mesh, rig, all blend shapes, animation clips, embedded textures
- `clothing/<item_id>.glb` — one file per clothing item, blend shapes named identically to the base mesh

## `base_mesh_placeholder.glb`

Not the commissioned art. This is a rough capsule humanoid generated by
`tools/blender/generate_placeholder_character.py`, used only to exercise the app
pipeline (morph targets, rig, animation clips) end to end before the artist delivers
`base_mesh.glb`. It matches the spec's measurable requirements — 1.75 m height, origin
between the feet, A-pose, glTF axis convention, all 18 required blend shape names,
`idle`/`celebrate`/`showcase` clips — but has none of the PSO2-style art direction.

To regenerate it, or after tweaking the generator script:

```
blender --background --python tools/blender/generate_placeholder_character.py -- \
    --output assets/characters/base_mesh_placeholder.glb
```

`tools/blender/render_preview.py` renders quick still previews of a `.glb` at a few
blend shape states, useful for a sanity check without opening Blender's UI:

```
blender --background --python tools/blender/render_preview.py -- \
    --input assets/characters/base_mesh_placeholder.glb \
    --outdir /tmp/character_previews
```

`tools/blender/validate_glb.py` is a pure-Python (no Blender) post-export QA gate — it
reloads the GLB and checks bounds (1.75 m, feet at ground, Y-up), skin attributes,
weight sums, max-4 influences, the 18 morph names, the 20 spec bone names, the 3
animation clips, and bind-pose joint positions (to catch a snapped rig). Exit code is
non-zero on any required failure, so it can gate CI:

```
python3 tools/blender/validate_glb.py assets/characters/base_mesh_placeholder.glb
```

The generator writes `base_mesh_placeholder_bounds_report.json` alongside the GLB with
the before/after normalization bounds. The rig uses the spec section 5 bone chain
(`shoulder → upper_arm → forearm → hand`, `thigh → shin → foot → toe`).

Once the artist hands off the real `base_mesh.glb`, drop it in this folder and update
the `require(...)` path in `App.tsx`.
